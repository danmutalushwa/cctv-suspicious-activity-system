# Intelligent CCTV System - Client

React frontend for the Intelligent CCTV-Based Suspicious Activity Detection System.

## Tech Stack

- **Framework:** React 18
- **Build Tool:** Vite 5
- **Routing:** React Router 6
- **State Management:** Context API + React Query
- **Styling:** Tailwind CSS 3
- **Forms:** React Hook Form
- **Charts:** Recharts
- **Real-time:** Socket.IO Client
- **HTTP:** Axios
- **Notifications:** React Toastify
- **Icons:** Lucide React
- **Testing:** Vitest + Testing Library

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Copy environment variables
cp .env.example .env

# Start development server
npm run dev
```
