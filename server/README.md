# Backend — Node.js & Express

This directory contains the Node.js/Express backend of the Intelligent CCTV-Based Suspicious Activity Detection System.

The backend serves as the central business logic and API layer between the React client, MongoDB database, and Python AI service.

## Responsibilities

The backend is responsible for:

- User authentication and authorization
- Role-based access control
- User management
- CCTV video upload and management
- Video streaming and processing
- Incident management
- Alert management
- Evidence management
- AI service integration
- AI detection result processing
- Automatic incident creation
- Automatic alert creation
- Database operations
- API validation and error handling
- Real-time communication using Socket.IO
- Application logging

↓

## Routes

Define the API endpoints and connect incoming requests to the appropriate controllers.

## Middleware

Handles cross-cutting concerns such as:

- Authentication
- Authorization
- File uploads
- Request validation
- Error handling

## Controllers

Handle HTTP requests and responses.

Controllers receive requests, execute the required business operation through services, and return responses to the client.

## Services

Contain the main application business logic.

Important services include:

- ai.service.js — communicates with the Python AI service
- ai-incident.service.js — converts AI detections into incidents and alerts
- video.service.js — handles video-related operations

## Models

Mongoose models define the application’s database entities and provide access to MongoDB.

Main entities include:

- Users
- Videos
- Incidents
- Alerts
- Evidence
- Cameras

## Incident Management

The backend creates and manages incidents generated by the AI system or other application sources.

An incident can contain:

- Incident type
- Severity
- Status
- Description
- Detection confidence
- Bounding box
- Detection timestamp
- AI analysis
- Detection reason
- Track ID
- Video reference
- Evidence

## Supported suspicious activity types include:

Intrusion
Loitering
Rapid Movement
Suspicious Behavior

## Alert Management

When suspicious activity is detected, the backend can automatically create an alert associated with the incident.

Alerts contain information such as:

- Title
- Message
- Priority
- Severity
- Incident reference
- Camera reference
- Detection reason
- Activity type
- Timestamp

## Authentication

The backend uses JWT-based authentication to protect API resources.

Protected endpoints require a valid authentication token.

Role-based authorization controls access to different parts of the system.

## File Management

The backend manages uploaded CCTV videos and evidence files.

uploads/

The backend also provides video streaming functionality for the client application.

http://localhost:5000

GET /api/health

Environment Configuration

The backend uses environment variables for configuration.

NODE_ENV=development
PORT=5000
MONGODB_URI=mongodb://localhost:27017/cctv_suspicious_activity
JWT_SECRET=your-secret-key
AI_SERVICE_URL=http://localhost:5001
AI_API_KEY=your-ai-api-key
CLIENT_URL=http://localhost:3000

The .env file should not be committed to the repository.

Backend Role in the System

The Node.js backend acts as the core business layer of the application.

It connects the user interface, database, and AI service while enforcing the application’s business rules.

              ┌─────────────────┐
              │   React Client  │
              └────────┬────────┘
                       │
                       ▼
              ┌─────────────────┐
              │  Node.js API    │
              │ Business Logic  │
              └───────┬─────────┘
                 ┌────┴────┐
                 ▼         ▼
          ┌──────────┐  ┌────────────┐
          │ MongoDB  │  │ Python AI  │
          └──────────┘  └────────────┘

This separation keeps the user interface, business logic, data persistence, and AI processing independent and easier to maintain.
